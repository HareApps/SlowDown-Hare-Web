# 🐇 SlowDown HareApp

> **Rest your eyes, refresh your mind.**  
> Inteligentny asystent przerw, który dba o Twoją higienę pracy przy komputerze.

SlowDown HareApp to nowoczesna aplikacja webowa zaprojektowana w estetyce **Glassmorphism**, która pomaga użytkownikom utrzymać zdrowe nawyki poprzez regularne przypomnienia o przerwach.

---

## ✨ Funkcje

- 🕒 **Elastyczne Interwały**: Wybierz czas pracy od 30 minut do 4 godzin.
- ⏳ **Tryb Odliczania**: Dyskretne działanie w tle z możliwością podglądu pozostałego czasu.
- 🔔 **Inteligentne Alerty**: Powiadomienia o konieczności zrobienia przerwy z opcją "Odpocznij teraz" lub "Odłóż".
- 🎵 **Powiadomienia Dźwiękowe**: Sygnał audio przy każdym alercie.
- 🧘 **Sesje Relaksacyjne**: Dedykowany ekran relaksu z kojącą grafiką.
- 📱 **PWA & Offline**: Możliwość instalacji na telefonie i działania bez dostępu do internetu.
- 🎨 **Modern UI**: Interfejs oparty na przezroczystościach, rozmyciach i płynnych animacjach.

## 🖼️ Zasoby Multimedialne (Wymagane)

Aplikacja korzysta z własnych zasobów, które należy umieścić w głównym katalogu repozytorium:
- `zorza.jpg` - Tło ekranu relaksu.
- `hare_relax.JPG` - Obrazek na ekranie alertu.
- `soundreality-notification-piano-443094.mp3` - Dźwięk powiadomienia.

## 🛠️ Jak uruchomić lokalnie?

1. **Zainstaluj zależności**:
   ```bash
   npm install
   ```
2. **Uruchom serwer deweloperski**:
   ```bash
   npm run dev
   ```
3. **Otwórz w przeglądarce**: `http://localhost:3000`
